Identity · DNA

Core Brand Identity

BrandMatrix defines how every expression of the AnLoMinus universe looks and feels: from GitHub repos and 4K banners to physical card decks and posters.

Essence & Personality
Core
  • ✨Holy–cosmic energy with a modern digital edge.
  • ⚡Powerful, uplifting, motivational and precise.
  • 🌌Deep, mystical, but always clear and readable.
  • 💎Premium feeling: gold, glow, and clean composition.
Visual Language
Direction
  • 🌠Cosmic backgrounds, depth and layered gradients.

Fonts · Hierarchy

Typography Guide

Clear hierarchy turns complex cosmic ideas into readable, shareable content across GitHub, sites and cards.

Web & GitHub
Digital
  • 🪐Headlines (H1–H2): bold, 110–140% line-height, letter-spacing +2%.
  • 📘Subtitles: medium weight, slightly muted color (#e5e7eb).
  • 📄Body: regular weight, 15–16px, color #d1d5db.
  • 💻Code blocks: monospace, dark background, light border.
Cards & Print
Physical
  • 🧱Card title: big, central, high contrast.
  • 🖋Sub text: few lines only – keep messages sharp.
  • 🎴Use same fonts across all decks for unity.
  • ✨Add small glow or outline to titles for holographic feel.
h1.hero-title // main message, cosmic + holy
h2.section-title // section headers, uppercase, spaced
p.section-sub // explanation text, calm and readable
.small-note // extra info: dates, versions, credits
Rules · Consistency

Brand Usage Rules

Simple rules that keep every new repository and creative product inside the same universe.

GitHub Repositories
Code
  • 📂Each repo: hero image in same color language.
  • 🧭Use BrandMatrix colors in README badges and headers.
  • 🔗Footer with: © AnLoMinus · BrandMatrix style tag.
Cards & Decks
Design
  • 🎴Keep frame style: dark edges, glowing center.
  • 💠Same gold/purple/glow logic for all sets.
  • 📌Add small “BM” mark on back or corner for identity.
Social & Banners
Social
  • 📱Use same cosmic background family on every banner.
  • 🕯Always one clear focal point: title or symbol.
  • 🚨Never mix random bright colors outside the palette.
